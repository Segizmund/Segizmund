### 👨‍💻 About Me

Full-Stack Developer with 3+ years of experience, specializing in the **Laravel + React (TypeScript, Inertia.js)** stack. 

Designed and launched 10+ web services: from large-scale university portals and ERP systems serving 1500+ users to interactive 2D/3D mapping solutions. 

Focused on building scalable architecture: designing databases and RBAC models, developing reactive SPA interfaces with Tailwind CSS, and integrating complex external APIs (geospatial services, weather data, telephony).
